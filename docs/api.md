# RemixTV Server API

## Базовый URL

```
http://{host}:{port}
```

## Аутентификация

Админские endpoints защищены HTTP Basic Auth. Если в настройках заданы `ADMIN_USERNAME` и `ADMIN_PASSWORD`, все запросы к админским endpoints требуют заголовок:

```
Authorization: Basic base64(username:password)
```

## Клиенты

### Регистрация клиента

Клиенты регистрируются автоматически при первом подключении. Дополнительных действий не требуется.

### Получение списка клиентов

```
GET /api/clients
```

**Требует:** аутентификацию админа

**Response:**
```json
[
  {
    "id": 1,
    "client_id": "93f95f7f-d177-48f0-a673-697b38fb4c5d",
    "name": "Терминал 1",
    "is_active": false,
    "is_online": true,
    "last_sync": "2026-04-12T15:30:00Z",
    "synced_playlist_version": 3,
    "last_status": "Воспроизведение"
  }
]
```

**Поля:**
- `is_online` — true, если было обращение за последние 10 минут

### Активация/деактивация клиента

```
PUT /api/clients/{id}/toggle
```

**Требует:** аутентификацию админа

**Body:**
```json
{
  "is_active": true
}
```

### Обновление имени клиента

```
PATCH /api/clients/{id}
```

**Требует:** аутентификацию админа

**Body:**
```json
{
  "name": "Новое имя"
}
```

### Удаление клиента

```
DELETE /api/clients/{id}
```

**Требует:** аутентификацию админа

## Синхронизация

### Получение плейлиста

```
GET /api/sync?client_id={uuid}
```

**Параметры:**
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| client_id | UUID | Да | Идентификатор клиента |

**Response (200 OK):**
```json
{
  "playlist_version": 5,
  "items": [
    {
      "playlist_item_id": 1,
      "video_id": 3,
      "filename": "video.mp4",
      "download_path": "/api/download/3?client_id=...",
      "file_hash": "d41d8cd98f00b204e9800998ecf8427e",
      "version": 1,
      "file_size": 1048576,
      "order": 0
    }
  ]
}
```

**Response (403 Forbidden)** — клиент не активирован:
```json
{
  "detail": "Клиент не активирован. Обратитесь к оператору."
}
```

### Скачивание видео

```
GET /api/download/{video_id}?client_id={uuid}
```

**Параметры:**
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| video_id | int | Да | ID видео |
| client_id | UUID | Да | Идентификатор клиента |

**Headers в ответе:**
- `X-Video-MD5` — MD5 хеш файла
- `X-Video-Version` — версия файла

**Response (403 Forbidden)** — клиент не активирован:
```json
{
  "detail": "Клиент не активирован. Обратитесь к оператору."
}
```

### Отправка статуса клиента

```
POST /api/client/status?client_id={uuid}
```

**Параметры:**
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| client_id | UUID | Да | Идентификатор клиента |

**Body (опционально):**
```json
{
  "detail": "Воспроизведение",
  "synced_playlist_version": 3
}
```

## Видео (Админка)

### Загрузка видео

```
POST /upload
```

**Требует:** аутентификацию админа

**Body:** `multipart/form-data`
- `file` — видеофайл

**Поддерживаемые форматы:** mp4, mkv, webm
**Response:**
```json
{
  "id": 1,
  "filename": "video.mp4",
  "file_path": "video.mp4",
  "duration": 120.5,
  "file_size": 1048576,
  "file_hash": "d41d8cd98f00b204e9800998ecf8427e",
  "version": 1,
  "upload_date": "2026-04-12T15:30:00Z"
}
```

**Примечание:** При загрузке файла с таким же именем существующее видео обновляется (новая версия).

### Получение списка видео

```
GET /api/videos
```

**Требует:** аутентификацию админа

### Переименование видео

```
PATCH /api/videos/{video_id}
```

**Требует:** аутентификацию админа

**Body:**
```json
{
  "filename": "Новое имя.mp4"
}
```

**Ограничения:**
- Имя файла не может содержать `/` или `\`
- Имя файла не может быть пустым

### Удаление видео

```
DELETE /api/videos/{video_id}
```

**Требует:** аутентификацию админа

Удаляет видео из библиотеки и с диска.

### Очистка библиотеки

```
DELETE /api/videos
```

**Требует:** аутентификацию админа

Удаляет все видео из библиотеки и папку uploads.

**Response:**
```json
{
  "detail": "Удалено видео: 5"
}
```

### Предпросмотр видео

```
GET /api/videos/{video_id}/preview
```

**Требует:** аутентификацию админа

Возвращает видео с правильным Content-Type для воспроизведения в браузере.

### Скачивание видео (админка)

```
GET /api/videos/{video_id}/download
```

**Требует:** аутентификацию админа

Скачивает видеофайл на устройство.

## Плейлист (Админка)

### Получение плейлиста

```
GET /api/playlist
```

**Требует:** аутентификацию админа

### Добавление видео в плейлист

```
POST /api/playlist
```

**Требует:** аутентификацию админа

**Body:**
```json
{
  "video_id": 1,
  "start_date": "2026-04-12T00:00:00Z",
  "end_date": "2026-04-20T23:59:59Z",
  "is_active": true
}
```

### Обновление элемента плейлиста

```
PUT /api/playlist/{item_id}
```

**Требует:** аутентификацию админа

**Body:**
```json
{
  "start_date": "2026-04-13T00:00:00Z",
  "end_date": null,
  "is_active": false
}
```

### Удаление из плейлиста

```
DELETE /api/playlist/{item_id}
```

**Требует:** аутентификацию админа

### Изменение порядка плейлиста

```
POST /api/playlist/reorder
```

**Требует:** аутентификацию админа

**Body:**
```json
{
  "items": [
    {"id": 1, "order": 0},
    {"id": 2, "order": 1},
    {"id": 3, "order": 2}
  ]
}
```

## Коды ошибок

| Код | Описание |
|-----|----------|
| 400 | Bad Request — некорректные данные |
| 401 | Unauthorized — требуется авторизация |
| 403 | Forbidden — клиент не активирован |
| 404 | Not Found — ресурс не найден |
| 409 | Conflict — конфликт (например, видео уже в плейлисте) |
| 422 | Unprocessable Entity — ошибка валидации |
| 500 | Internal Server Error — ошибка сервера |

## Установка как сервис (Linux/systemd)

Скопируйте файл `docs/remixtv.service` в `/etc/systemd/system/`:

```bash
sudo cp docs/remixtv.service /etc/systemd/system/remixtv.service
```

Отредактируйте пути и пользователя в файле:
```bash
sudo nano /etc/systemd/system/remixtv.service
```

Управление сервисом:
```bash
# Перезагрузка конфигурации
sudo systemctl daemon-reload

# Запуск
sudo systemctl start remixtv

# Автозапуск при загрузке
sudo systemctl enable remixtv

# Статус
sudo systemctl status remixtv

# Перезапуск
sudo systemctl restart remixtv

# Остановка
sudo systemctl stop remixtv
```
